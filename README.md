# استودیوی برند · Brand Studio

ابزار ویرایش قالب‌های اینستاگرام و ویدیو برای چند برند، فارسی و راست‌به‌چپ. روی GitHub Pages اجرا می‌شود و به سرور جداگانه نیاز ندارد.

**نشانی:** https://yashcistudy.github.io/brand-studio/

## چه چیزهایی قابل ویرایش است

| لایه | کجا | چه چیزی |
|---|---|---|
| برند | «هویت برند» | رنگ‌ها، گرادیان‌ها، پوسته‌ها (نقش‌های رنگ مثل ‎@text و ‎@card)، فونت‌ها، سبک‌های متن، لوگوها و دسته‌های لوگو |
| قالب | «ویرایشگر» | محتوا و فیلدها، لایه‌ها (افزودن، حذف، جابه‌جایی، پنهان کردن)، ویژگی هر عنصر، عناصر شناور قابل کشیدن، اندازه، پوسته |
| مجموعه‌ها | «توالی‌ها» و «شبکه و هایلایت» | ترتیب کاروسل و استوری، شبکهٔ پروفایل، هایلایت‌ها |
| اندازه‌ها | «اندازه‌ها» | اندازه‌های سفارشی، محدودهٔ امن، نوار رابط اپ، برش شبکه |

## ذخیره

1. **خودکار در مرورگر:** هر تغییر در IndexedDB همان مرورگر ذخیره می‌شود.
2. **انتشار در گیت‌هاب:** در بخش «ذخیره و انتشار» یک توکن fine-grained با دسترسی *Contents: Read and write* فقط برای همین مخزن بسازید. هر برند در `brands/<id>/brand.json` و فایل‌هایش در پوشهٔ همان برند ذخیره می‌شود.
3. **فایل پروژه:** برای پشتیبان‌گیری یا فرستادن به همکار، یک فایل ‎.json کامل (همراه تصویرها) دانلود کنید.

## ساختار

```
index.html
css/app.css
js/engine.js      رندر قاب از داده (چیدمان خودکار + عناصر شناور)
js/app.js         ویرایشگر
js/store.js       IndexedDB، فایل پروژه، انتشار در گیت‌هاب
js/vendor/html-to-image.js   ساخت PNG (محلی، بدون CDN)
data/formats.json            اندازه‌ها
brands/index.json            فهرست برندها
brands/<id>/brand.json       هر برند: توکن‌ها، فونت‌ها، لوگوها، قالب‌ها
```

## افزودن برند تازه

«+ برند تازه» را بزنید. برند می‌تواند خالی (با سه قالب پایه) شروع شود یا کپی کامل یک برند موجود باشد. بعد رنگ، فونت و لوگو را در «هویت برند» عوض کنید و منتشر کنید.

> ⚠️ **این مخزن عمومی است.** هر فونت، لوگو یا تصویری که منتشر شود، برای همه قابل دانلود است. مجوز فونت‌های تجاری (کلمه، پیدا) و اجازهٔ انتشار لوگوی مشتری را بررسی کنید.
